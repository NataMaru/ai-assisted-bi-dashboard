# 📊 Interactive E-commerce Dashboard & AI Assistant

**Role:** Data Analyst (AI-Assisted Development)

This project was created to demonstrate a Proof of Concept (PoC) for an interactive sales analytics dashboard. The main goal is to showcase the data interaction logic and the behavior of the built-in AI assistant before passing the project to the development team.

---

* 🚀 **Live Demo**: [Open Live Dashboard](https://nata-maru-genai-bi-dash.netlify.app/)

---

## ⏱️ Timeline & Efficiency
* **Development Time**: ~1.5 hours (from initial idea and data preparation to deploying the live website).
* This project serves as an example of how a data analyst can leverage modern AI tools to independently and rapidly build a functional Minimum Viable Product (MVP) to pitch to stakeholders.

---

## 🎯 My Contribution as a Data Analyst:
* **Data Preparation**: Structured the e-commerce mock data used to populate the charts (data.csv file).
* **Prompt Engineering**: Crafted detailed technical prompts for Claude AI to generate the dashboard structure and chat assistant logic.
* **Tuning & Testing**: Conducted functional business testing of the interface, adjusted the bot's responses to match business KPIs, and validated data consistency.
* **Deployment**: Independently hosted the code on a free hosting platform to demonstrate front-end viability.

---

## 💻 Technical Stack & Implementation (For Developers)
* Code fully generated via **Claude AI** using HTML, CSS, and JS.
* All data and chat logic run entirely on the client side (no back-end infrastructure required for this prototype).
* Ready to be handed over to a development team for integration with production databases and APIs.

---

## 🚀 Future Iterations & Enhancements (Product Backlog)
In my YouTube walkthrough, I analyze the project's growth areas. To scale this prototype into a production-ready product, the development team should consider:
1. **Database Integration**: Migrate the dashboard from static data to dynamic data fetching via API (e.g., connecting to PostgreSQL or Google BigQuery).
2. **Advanced AI Integration**: Connect the chatbot component to an official LLM API (Anthropic) to allow dynamic chart generation based on user text queries.
3. **Deeper Analytics**: Introduce sections for Cohort Analysis and Predictive Analytics for sales forecasting based on historical trends.
