# Prompt Used for Claude AI

Below is the exact text prompt used to generate the dashboard and assistant logic:

Ти — передова система AI-Native BI (Generative BI). Твоє завдання — створити для мене повноцінний інтерактивний веб-додаток (інформаційну панель) за допомогою функції Artifacts на основі доданого файлу. Інтерфейс має складатися з двох частин: 1. нижня панель : Вікно чату з "AI-аналітиком", де користувач може писати запити звичайною мовою. 2. верхня панель : Живий інтерактивний дашборд із графіками (використовує сучасні бібліотеки візуалізації, наприклад, Tailwind CSS та Recharts / Chart.js через CDN). Вимоги до функціонального макету: - Дашборд повинен мати початковий вигляд (наприклад, 2-3 базові картки з KPI та один головний тренд-графік). - Система має симулювати перебудову графіків по запиту в чаті ! Напишіть логіку на JavaScript так, щоб коли користувач обирає в чаті або вводить запити (наприклад: "зміни типу графіка", "покажи топ продукт", "відфільтруй за регіоном"), графіки на сусідній панелі динамічно оновлювалися, перемальовувалися та змінювали свій стан. Зроби дизайн сучасним, чистим та професійним, кольори мають бути приглушеними та не більше двох основних кольорів. Додай підпис данних на графіках але не первантажуй сильно.  Додай також фільтри для періоду, категорій та регіона. Не використовуй діаграми пироги, замість них краще стовпчикові горизонтальні діаграми.  Напишіть весь код (HTML, CSS, JS) в одному файлі всередині Artifact.
